## 핵심 결정 (사용자 확정)
- 범위: 화면 + 흐름 재구성, 데이터 모델 변경 허용
- 사업팀 3대 고충: 기능(모듈) 선택 · 개발팀 질문 회신 · 확정 후 처리

## 핵심 제안 5가지
1. **체험 단계 요청서**: 기능 선택 + 화면 구성 두 경로를 "방문객이 무엇을 하나요?" 하나로 합치고, 모듈은 자동 매핑.
2. **확인 요청 카드**: 댓글 질문을 "금액 영향 / 진행 확정 때" 구조화된 질문으로. 회신 대기가 목록에 보인다.
3. **내 차례 홈**: 견적마다 다음 행동 주체와 행동 한 줄. 상세 페이지 하단 버튼 7~8개 → 단계별 주요 행동 1개.
4. **발송본 버전**: 승인할 때마다 v1, v2… 스냅샷. Excel·비교는 스냅샷 기준.
5. **확정 후 체크리스트**: 자료(시안·코드) + 착수 준비(노션·폴더·베이스 코드·담당) + 금액 없는 개발 보드.
